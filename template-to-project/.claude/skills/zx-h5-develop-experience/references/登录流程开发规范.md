# 登录流程开发规范 (Login Standards)

## 核心 API (zUser)

统一使用 `zUser` 处理用户登录相关操作（判断登录状态、发起登录流程）。

```typescript
import { zUser } from '@ctrip/xtaro-zx-h5';
```

## 1. 环境与原理 (Environments & Principles)

智行 H5 页面运行在三种主要环境中，登录行为各不相同：

| 环境 | 表现 | 登录原理 |
| --- | --- | --- |
| **APP 内** | **弹窗** | 调用 Native 登录弹窗。登录成功后关闭弹窗，Native 写入 Cookie，触发 Promise 回调。页面**不刷新**。 |
| **小程序内** | **跳转** | Redirect 到小程序登录页。登录成功后 Redirect 回原页面。**页面会刷新** (Cookie 由服务端中间件注入)。 |
| **浏览器** | **跳转** | Redirect 到 H5 登录页。登录成功后 Redirect 回原页面。**页面会刷新** (Cookie 由登录页写入)。 |

**关键结论**:
1.  **APP 环境**: 代码会继续执行到 `then()`。
2.  **非 APP 环境**: 页面会刷新，JS 上下文重置，`then()` 不会被执行。

## 2. 编码策略 (Coding Strategy)

为了代码复用，**请统一按照 APP 环境的 Promise 模式编写**。

### 标准代码模式

```javascript
import { zUser, xShowToast } from '@ctrip/xtaro-zx-h5';

async function handleUserAction() {
    try {
        // 1. 判断是否登录
        const isLogin = await zUser.isLogin();
        
        if (isLogin) {
            // 已登录：执行业务
            doBusinessLogic();
        } else {
            // 2. 未登录：发起登录
            zUser.login()
                .then(() => {
                    // [APP Only] 登录成功回调
                    // 在 H5/小程序中，页面已刷新，这里不会执行，但也无副作用
                    doBusinessLogic();
                })
                .catch((err) => {
                    // [APP Only] 登录被取消或失败
                    // 通常是用户点击了关闭弹窗
                    xShowToast({ title: '已取消登录' });
                });
        }
    } catch (e) {
        // [Exception] isLogin 接口本身异常 (罕见)
        console.error('Check login failed', e);
        throw e;
    }
}
```

### 异常处理细节 (Error Handling Rules)

1.  **`zUser.isLogin()` Reject**:
    *   **含义**: 接口调用失败（如网络错误、Bridge 失败）。
    *   **处理**: 属于**异常**，应该被外层 `try-catch` 捕获并 `throw`。
2.  **`zUser.login()` Reject**:
    *   **含义**: 用户**取消登录**（如关闭弹窗）或登录操作失败。
    *   **处理**: **不属于异常**。通常给予用户提示（如 Toast），**不需要 `throw`**。

## 3. Agent 常见误区

- **误区**: 试图根据 `UA` 判断环境写两套逻辑（一套跳转，一套弹窗）。
- **纠正**: **严禁**手动判断环境。`zUser.login()` 内部已封装环境判断，直接调用即可。
- **误区**: 认为 `login()` 返回的 Promise 在所有环境都会 resolve。
- **纠正**: 仅在 APP 环境会 resolve。但写法上假定它会 resolve 即可。
