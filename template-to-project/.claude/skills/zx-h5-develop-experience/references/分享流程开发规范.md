# 分享流程开发规范 (Sharing Standards)

## API 概览

| 功能 | API / 组件 | 描述 |
| --- | --- | --- |
| **弹窗分享** | `ZShareModal` | **推荐**。底部弹起分享面板，支持自定义按钮和海报。 |
| **直接分享** | `zShare.share()` | 直接拉起特定渠道（如微信好友）分享。 |
| **数据设置** | `zShare.setMiniShareData()` | 仅设置小程序右上角“...”胶囊菜单的分享内容。 |

## 1. 数据结构定义 (TypeScript)

Agent 在生成代码时，**必须**遵循以下类型定义。

```typescript
type Platform = 'WeixinFriend' | 'WeixinCircle' | 'SaveImage';
type ShareType = 'miniProgram' | 'image' | 'link';

/**
 * 通用分享参数接口
 * 适用于 zShare.share() 和 ZShareModal operation
 */
interface ZShareParams {
  // --- 环境配置 (Critical) ---
  
  /** APP 环境下的分享配置 */
  app: {
    platform: Platform;
    shareType: ShareType;
  };
  
  /** 小程序/H5 环境下的分享配置 */
  mini: {
    platform: Platform;
    shareType: ShareType;
  };

  // --- 内容参数 (Content) ---

  /** 
   * 小程序路径 
   * @required 当 shareType='miniProgram' 或在小程序环境时必填
   * @example "/functionalPages/twebview/index?url=..." 
   */
  miniProgramPath: string;

  /** 
   * 小程序卡片/海报图片 URL
   * @required 必填，严禁为空
   * @note 小程序端不支持 base64，必须是 HTTPS 链接
   */
  miniProgramImage: string;

  /** 
   * 大图/海报图片 URL
   * @required 必填
   */
  image: string;

  /** 
   * H5 链接
   * @required 当 shareType='link' 时必填
   */
  link?: string;

  /** 
   * 标题
   * @description 小程序卡片或链接卡片的标题
   * @required 当 shareType='link' 或 'miniProgram' 时必填
   * @default miniProgram时不传为空; link时不传默认为链接Host
   */
  title?: string;
  
  /** 描述文字 (shareType='link' 时支持) */
  desc?: string;

  /** 
   * 业务类型 (bizType)
   * @description APP 跳转前默认有确认弹窗。若需关闭，请申请 bizType 后传入。H5 环境仅在 APP 内嵌时有效。
   * @link https://trip.larkenterprise.com/wiki/EJKwwuhk5iNmR4kuABZcTj5TnAh
   */
  bizType?: string;

  /** 埋点 Source */
  source?: string;
}

/**
 * 设置小程序胶囊菜单分享参数
 */
interface SetShareMiniDataParams {
  /** 小程序卡片标题 (必填) */
  title: string;
  /** 小程序卡判图片 (必填) */
  miniProgramImage: string;
  /** 小程序页面路径 (必填) */
  miniProgramPath: string;
}
```

## 2. 环境支持差异 (Environment Support)

| API | H5 | 小程序 | RN | 备注 |
| --- | --- | --- | --- | --- |
| `share` | ✅ | ✅ | ✅ | 通用分享 |
| `setMiniShareData` | ✅ | ✅ | ❌ | 仅设置小程序胶囊菜单分享内容 |

## 3. 常用场景示例 (Common Scenarios)

### 场景 1: 底部弹窗分享 (推荐)

使用 `ZShareModal` 组件。

```tsx
import { ZShareModal } from '@ctrip/xtaro-zx-h5';

const ShareComponent = () => {
    // 准备数据
    const commonParams = {
        image: 'https://images.ctrip.com/poster.png',
        miniProgramImage: 'https://images.ctrip.com/card.png',
        miniProgramPath: '/pages/home/index?source=share',
        source: 'my_biz_page'
    };

    const operations = [
        {
            name: '微信好友',
            // 分享为小程序卡片
            app: { platform: 'WeixinFriend', shareType: 'miniProgram' },
            mini: { platform: 'WeixinFriend', shareType: 'miniProgram' },
            ...commonParams
        },
        {
            name: '朋友圈',
            // 分享为海报图片
            app: { platform: 'WeixinCircle', shareType: 'image' },
            mini: { platform: 'WeixinCircle', shareType: 'image' },
            ...commonParams
        },
        {
            name: '保存图片',
            app: { platform: 'SaveImage', shareType: 'image' },
            mini: { platform: 'SaveImage', shareType: 'image' },
            ...commonParams
        }
    ];

    return (
        <ZShareModal
            visible={showShare}
            poster={commonParams.image}
            operations={operations}
            onClose={() => setShowShare(false)}
        />
    );
};
```

### 场景 2: 点击按钮直接分享 (Direct Share)

不弹窗，直接拉起微信好友分享。

```typescript
import { zShare } from '@ctrip/xtaro-zx-h5';

const handleShareArgs = () => {
    zShare.share({
        // 同时配置 APP 和 Mini 的行为
        app: { platform: 'WeixinFriend', shareType: 'miniProgram' },
        mini: { platform: 'WeixinFriend', shareType: 'miniProgram' },
        
        // 必填参数
        title: '分享标题',
        miniProgramPath: '/pages/target/index',
        miniProgramImage: 'https://img.com/card.png', 
        image: 'https://img.com/poster.png',
        source: 'direct_share_btn'
    });
};
```

### 场景 3: 分享纯链接 (Link Share)

```typescript
zShare.share({
    app: { platform: 'WeixinFriend', shareType: 'link' },
    mini: { platform: 'WeixinFriend', shareType: 'link' },
    
    link: 'https://m.ctrip.com/html5/index',
    title: '链接标题',
    desc: '这是链接描述',
    
    // 以下参数在 Link 模式下仍需传入以防环境降级
    miniProgramPath: '/pages/index',
    miniProgramImage: 'https://img.com/icon.png',
    image: 'https://img.com/icon.png'
});
```

### 场景 4: 设置小程序胶囊菜单 (Set Mini Menu)

```typescript
// 建议在页面加载完成后调用
useEffect(() => {
    zShare.setMiniShareData({
        title: '自定义胶囊分享标题',
        miniProgramImage: 'https://img.com/card.png',
        miniProgramPath: '/pages/current/index'
    });
}, []);
```

## 4. Agent 校验清单 (Checklist)

- [ ] **必填项检查**: `miniProgramPath` 和 `miniProgramImage` 是否已填？(即使是 Link 模式也建议填上作为兜底)
- [ ] **图片协议**: 所有图片 URL 必须是 `https://` 开头。
- [ ] **双端配置**: 是否同时配置了 `app` 和 `mini` 字段？
