# 埋点规范 (Tracking Standards)

## 核心 API

所有 H5 埋点统一使用 `xUbt`。

```typescript
import { xUbt } from "@ctrip/xtaro-zx-h5";

// 接口定义
interface LogTrace {
  (
    key: string, // 埋点 Key (由 PRD 提供)
    info: Record<string, any>, // 业务参数
    extend?: Record<string, any> // 扩展参数 (如有 eNum 等特殊字段需放入此处)
  ): void;
}
```

## 1. 埋点原则 (Rules)

1.  **PRD 驱动**: 只有当需求文档 (PRD) 或任务描述中明确提供了 `Trace Key` 和参数时才添加埋点。**严禁** Agent 自动生成“猜测性”的埋点（如 `Page_View`）。
2.  **按需上报**:
    - **曝光 (Exposure)**: 页面或组件可见时上报。
    - **交互 (Interaction)**: 用户点击、滑动等操作时上报。
3.  **参数完整**: 确保必填参数（如 `PageId`、`OrderId`）从上下文或 Props 中获取并传递。

## 2. 代码模式 (Code Patterns)

### 场景 A: 页面/组件曝光 (Exposure)

**Pattern**: 使用 `useEffect` (React) 或生命周期钩子。

```tsx
import { useEffect } from "react";
import { xUbt } from "@ctrip/xtaro-zx-h5";

const MyPage = ({ orderId }) => {
  useEffect(() => {
    // [Pattern] 仅在组件挂载时上报一次
    xUbt.logTrace("Page_Exposure_Key", {
      orderId: orderId,
      action: "view",
    });
  }, [orderId]); // 依赖项变化时可能需要重新上报，视需求而定

  return <div>...</div>;
};
```

### 场景 B: 用户点击 (Click)

**Pattern**: 在事件处理函数**首行**上报。

```tsx
const handleClick = () => {
  // [Pattern] 先埋点，再处理逻辑
  xUbt.logTrace("Button_Click_Key", {
    type: "confirm_button",
  });

  // 业务逻辑
  submitData();
};
```

## 3. Agent 校验清单

- [ ] **Key 准确性**: 埋点 Key 是否与需求文档完全一致（复制粘贴，不手敲）？
- [ ] **位置正确性**: 曝光埋点是否在 `useEffect` 中？点击埋点是否在 `onClick` 中？
- [ ] **参数非空**: 关键业务参数（如 ID）是否确保有值？
